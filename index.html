02Applied AI engineering

Four photo-to-structured-data apps pairing an LLM pipeline with a small model locally fine-tuned (LoRA) on the same task, each benchmarked base vs. fine-tuned vs. Claude zero-shot.

ProjectMethodsLinks
Cellar ScannerPhotograph a wine label for a grounded profile and food pairings cited to real reviews; a fine-tuned Qwen2.5-1.5B LoRA guesses grape variety from a blind tasting note alone, beating Claude's zero-shot Top-1 (27.7% vs. 23.0%).LiveWriteup
Menu DecoderPhotograph a restaurant menu for cuisine and allergen-risk tags per dish; a fine-tuned LoRA reaches 99.3% cuisine accuracy and 69.3% allergen recall from a bare dish name.LiveWriteup
Receipt AuditorPhotograph a receipt for automatic spend-category tagging; a fine-tuned LoRA reaches 90.5% category accuracy on held-out merchants, versus 27.7% for the base model and 56.0% for zero-shot Claude.LiveWriteup
Race Day CopilotPhotograph a race course map for a verified km-by-km pacing plan checked against five deterministic rules; a fine-tuned Qwen2.5-3B LoRA reaches near-parity with Claude on structure and plausibility.LiveWriteup
